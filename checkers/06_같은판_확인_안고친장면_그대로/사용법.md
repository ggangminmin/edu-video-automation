# 같은 판 확인 — 안 고친 장면이 정말 그대로인가

## 1) 길이가 같은 두 판: framediff.py (이 폴더)
`python3 framediff.py 앞판.mp4 새판.mp4 결과.json`
- 프레임마다 최대 차·평균 차·다른 화소 수를 적는다. 다른 화소 0 = 같은 그림.
- 바뀐 컷과 같은 2초 묶음(GOP)의 이웃 프레임은 재인코딩 잡음(평균차 약 0.1)으로 조금 다르게 나온다 → 그건 정상.
- 길이가 다르면(쉼을 넣거나 뺌) 뒤가 전부 「다름」으로 나온다 → 그때는 01_앞판새판_비교 의 qa_diff.py 를 쓴다.

## 2) 컷표(컷 목록 json)가 있는 판: same_as_cut.py — **프로젝트 전용 예**
위치: 국가데이터처 `_검수기_모음_261019/2_국가데이터처_전용/04_사례_마스터_전항목검수_세트/same_as_cut.py`(그 프로젝트 컷표 형식에 맞춰져 있음). 다른 프로젝트에서 컷 단위 비교가 필요하면 이걸 참고해 그 프로젝트 전용으로 만든다. 컷표가 없으면 01 또는 12 를 쓴다.
- 컷 단위로 맞춰 비교하므로 앞 컷 길이가 바뀌어도 뒤 컷을 제대로 비교한다. 소리(대사 줄)도 표본 단위로 비교.
- 먼저 같은 세트의 seg.py 로 두 판 모두 out_<판>/seg.json 을 만들어야 한다(세트 README 참고).

알려진 함정: 같은 길이·같은 시계인데 그림만 바뀐 판에서 자막 글자 대조(capdiff)를 「찾아 맞춤」 모드로 돌리면 엉뚱한 짝을 잡아 오탐이 쏟아진다 → 같은 프레임 번호끼리 직접 비교(SEARCH=0).
