# 받아쓰기 대본 대조 (스크립트 없음, 명령 두 줄)

무엇을 잡나: 대사가 씹히거나 빠진 곳, 같은 말이 두 번 나온 곳.

## 돌리는 법
1. 소리를 16k 모노로 뽑는다(대사 스템이 있으면 스템, 없으면 영상)
   `ffmpeg -v error -y -i 영상또는대사.wav -ac 1 -ar 16000 받아쓰기용.wav`
2. 받아쓰기
   `whisper-cli -m ~/.cache/whisper-cpp/ggml-large-v3-turbo.bin -l ko -oj -of 받아쓰기 -f 받아쓰기용.wav`
   → `받아쓰기.json`(6분짜리 약 11초)
3. 한글만 남겨 대본(컷표 narr 이어붙인 것)과 글자 대조 → 3글자 이상 빠지거나 다른 곳이 0 이면 통과.

## 결과 읽는 법
- 일치율 0.98 언저리면 정상(「판넬」「캐피」 같은 표기 흔들림).
- 단어별 시각이 필요하면 `-ml 1 -sow -ojf -dtw large.v3.turbo` 를 붙인다(토큰 시각 t_dtw).

## 알려진 오검출
- 끝 무음에서 「감사합니다」를 지어낸다 → 안 바뀐 곳에서 차이가 나면 그 구간만 잘라 다시 받아쓴다.
- 같은 글자가 겹치면 대조 경계가 돌아가 결손처럼 보인다(「다음은거처입니다」) → 회전 일치 허용.
- 소제목 카드 나레이션(「먼저 조사구입니다」 등)은 컷표 narr 에 없다 → 빼고 대조.
- 긴 쉼 뒤 첫 단어 시각이 0.5~0.7초 앞서 나온다(DTW 번짐).
- python whisper 모듈은 이 맥에 없다. whisper-cli 만 쓴다.
