# 검수기 — 모든 영상 프로젝트 공통

- 모든 영상 프로젝트가 여기 것을 쓴다. 결과는 `~/Movies/video_qa/` 에 생긴다(iCloud 밖).
- 프로젝트 전용 검수기(특정 캐릭터 입 모양 · 특정 앱 화면 대조 등)는 그 프로젝트 폴더에 둔다(예: 국가데이터처 `_검수기_모음_261019/2_국가데이터처_전용/`).
- 아래 설명 속 경로 「모음/1_어디서나_쓰는것/…」 = 이 폴더(`minstack/검수기/…`).

> 🆕10/19 **화면 설정 먼저.** 01 · 02 · 03 · 04 · 05 는 프로젝트의 자막바 위치 · 색을 `--screen <화면설정.json>`(또는 `export QA_SCREEN=…`)으로 받는다. 없으면 「자막바를 먼저 재라」로 멈춘다(01 은 설정 없으면 아래 22% 기본). 새 프로젝트 첫날 = `python3 minstack/도구/자막바_재기.py <영상> <자막 떠 있는 초 3~6개> --out <폴더>` → `자막바_확인.jpg` 를 눈으로 보고 `화면설정_초안.json` 을 프로젝트 `화면설정.json` 으로. 양식 = `검수기/화면설정_양식.json`, 예시 = `화면설정_예시_국가데이터처.json`.

## 게시 전 반드시 돌릴 것 (이 순서로)

1. **앞판·새판 비교**(01) — 직전에 보낸 판과 새 판을 비교해 「시키지 않은 곳이 바뀐 것」이 0 인지.
2. **전편 한 번에 검사**(05) — 자막 싱크·빈 자막바·검은 화면·합격 장면·직전 판과 자막 글자 비교를 한 줄로.
3. **지직 소리**(07) — 고친 장면 파일(배경음악 없는 것)에 돌린다. 합본에는 안 잡힌다.
4. **받아쓰기 대본 대조**(08) — 대사가 빠지거나 씹힌 곳이 0 인지.
5. 입이 나오는 장면을 새로 만들었으면 **입 모양 시트**(2_전용/01)로 기준작과 나란히 본다.

공통: 「프로그램이 끝까지 돌았다」 ≠ 「합격」. 걸린 곳은 반드시 그 시각 화면을 열어 눈으로 확인한다. 걸린 게 0이어도 자막 글자 바뀜·조립 실수는 도구마다 못 보는 칸이 있다(아래 「알려진 오검출」).

명령 속 `모음` = 이 폴더(`minstack/검수기`) 경로.

### 01_앞판새판_비교_시키지않은곳_바뀜
- 무엇을 잡나: 고치라고 한 곳 말고 다른 곳(화면·자막·소리)이 바뀐 것.
- 언제: 마스터를 보내기 직전, 매번.
- 명령: `python3 모음/1_어디서나_쓰는것/01_앞판새판_비교_시키지않은곳_바뀜/qa_diff.py 앞판.mp4 새판.mp4 --allow 10:17-10:25 --out ~/Movies/video_qa/이름`
  (`--allow` = 민석이 고치라고 한 시각, 여러 번 쓸 수 있음)
- 결과 읽기: `diff_report.md` 의 **「지적 밖 N곳」이 0** 이면 통과. 0이 아니면 줄마다 `sheets/` 의 앞|새 그림을 본다.
- 알려진 오검출: 쉼을 넣거나 빼서 시계가 바뀐 판(예: 1.6초 당겨짐)은 뒤 전체가 「바뀜」으로 쏟아진다(6강 221곳 오탐) → 구간마다 다시 맞춰 비교해야 한다. 같은 길이 판끼리는 믿어도 된다. **화면 구성이 전편에서 바뀐 판(5강 태블릿 이동)은 맞춘 비율 1.4% — 01 대신 12 를 쓴다.**
- 🆕10/19 시험 운행: 자동 그림(`sheets/`)은 **새판만** 보여 준다 → 검수 창이 앞판·새판 같은 시각을 뽑아 나란히 붙여야 민석이 「전·후」로 본다.
- 원본: `국가데이터처/_dev/qa/qa_diff.py` (+ `qa_feat.py`, 설명서 `HANDOFF_261013.md` 같이 복사)

### 02_자막_싱크_늦게뜸_일찍꺼짐
- 무엇을 잡나: 자막이 말보다 늦게 뜸(LATE), 말 도중 바뀜(MIDON), 말 도중 꺼짐(MIDOFF), 말 끝나고 오래 남음(LINGER), 장면이 바뀌었는데 앞 자막이 남음(CROSS), 글자 없는 바(EMPTY).
- 언제: 자막을 새로 얹거나 쉼을 바꾼 판. 보통은 05의 한 줄 검사 안에서 같이 돈다.
- 명령(단독): `python3 capsync.py subbar.json runs.json scd.log 결과이름 whisper.json` — 재료 만드는 순서는 05의 master_check.sh 를 그대로 따른다. 걸린 항목 2차 확인 = `verify_flags.py 마스터.mp4 capsync.json whisper.json 결과이름`
- 결과 읽기: `capsync_<이름>.md` 표. 항목마다 시각이 있으니 그 시각 화면을 연다.
- 알려진 오검출·못 잡는 것: ① 「다른 글자가 제때 뜬 것」(자막 누락·바뀜)은 못 잡는다 → 09로. ② 앞 화면 위에 다음 장면 자막이 1~3초 먼저 뜬 것을 못 잡은 적 있다(6강 5:52·13:29). ③ 긴 쉼 뒤 첫 단어는 받아쓰기 시각이 0.5~0.7초 앞서 나와 LATE 가 과장된다 → 대사 스템 말 구간으로 다시 본다. ④ 원형 와이프 한가운데를 장면 컷으로 잡으면 「바 먼저 꺼짐」 오탐.
- 원본: `~/Movies/kostat_R24/R28/QA2/` capsync.py · runs.py · verify_flags.py

- 알려진 오검출(공통): 화면 설정을 다른 프로젝트 것으로 주면 바 위치가 어긋나 「빈 바 0 · 자막 구간 0」처럼 조용히 통과한다 → 처음 한 번은 `자막바_확인.jpg` 를 눈으로 본다.

### 03_빈_자막바

- 원본: `~/Movies/kostat_R24/R28/QA2/subbar_scan.py`

### 04_합격장면_그대로_들어갔나

### 05_전편_한번에_검사
- 무엇을 잡나: 위 02·03·04 + 장면 컷 + 검은 화면(전 프레임) + I프레임 수 + 「말 있는데 자막 없음」 + (직전 판을 주면) 자막 글자 바뀜(09)을 한 번에.
- 언제: 마스터 후보가 나올 때마다.
- 명령: `PASSED=<합격 클립 폴더> zsh 모음/1_어디서나_쓰는것/05_전편_한번에_검사/master_check.sh --screen <화면설정.json> 마스터.mp4 대사스템.wav 이름표` — PASSED 기본값 없음(안 주면 합격 대조만 건너뛰고 알림)
  - 직전 후보와 글자 대조까지: 앞에 `PREV=직전이름표 PREVMP4=직전.mp4` 를 붙인다(같은 길이면 `SEARCH=0`).
  - 합격 클립 폴더: `PASSED=폴더`(기본 `~/Movies/kostat_R24/R26/passed` — 지금은 없는 폴더라 매번 지정).

  - 미리보기(소리가 영상에 같이 든 것)는 `preview_check.sh 미리보기.mp4 이름표`.

- 알려진 오검출: 02·03·04·09 각각의 것 그대로.
- 원본: `~/Movies/kostat_R24/R28/QA2/master_check.sh`, `preview_check.sh` — 복사본은 형제 폴더의 스크립트를 부르고 결과를 따로 쓰도록 고쳤다(원본은 QA2 폴더 안에서만 돌았음).

### 07_지직소리
