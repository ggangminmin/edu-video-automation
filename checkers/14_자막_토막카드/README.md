# 14 자막 토막 카드
- 무엇을 잡나: 한 문장을 자막 카드 여러 장으로 나눴는데 한 장이 너무 짧아(「공장에서는」「11강에서는」) 자막바가 비어 보이는 것 · 한쪽으로 쏠린 나눔.
- 왜 생겼나: 2026-11-09 마루시공 04~10강 민석 「좀 길어도 됨. 자연스럽게 자막바 채워지게」 — 18강 「소매와 끈, 장신구,」 다음 두 번째 같은 지적.
- 언제: 강의·나레이션 영상 자막을 새로 나누거나 고쳤으면 올리기 전 매번.
- 명령: `python3 minstack/검수기/14_자막_토막카드/short_card_check.py <타임라인.json | 자막.srt> [--min 10]` — 종료코드 0 = 통과.
- 기준: 같은 문장 카드 2장 이상일 때 ① 공백 뺀 10자 미만 ② 짧은 쪽/긴 쪽 < 0.45 이고 16자 미만. 한 카드짜리 문장은 안 봄.
- 고칠 때: 가운데 가까운 자연스러운 자리(연결어미·쉼표 뒤)에서 고르게 나누거나 한 장으로 합친다. 나눌 자리가 없으면 한 장 허용 = 글자 폭이 바 안쪽 85% 이하(마루시공 1500px).
- 검산(마루시공): 10강 v2 → 15 걸림(민석이 짚은 「공장에서는」「설치된 구역은」 포함) · 10강 v4b → 0 · 18강 v3c → 「소매와 끈, 장신구,」 걸림 · srt 시험 「공장에서는」 걸림. 프로젝트 원본 `회사 포폴용/261022_디애드 마루시공전문가/_작업/검수/검사기/short_card_check.py` 와 결과 같음.
- 못 보는 것: 뜻이 어색하게 끊긴 자리(글자 수가 충분하면 통과) · srt 는 문장 경계를 어미로만 짐작 → 「…고」「…며」로 끝나는 카드는 다음 카드와 같은 문장으로 봄. 통과 후 눈으로 한 번.
