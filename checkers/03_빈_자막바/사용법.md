# 03 빈 자막바 — 사용법 (10/19 화면 설정 분리)

- 명령: `python3 subbar_scan.py 마스터.mp4 결과.json --screen <화면설정.json>` (또는 `export QA_SCREEN=<화면설정.json>` 뒤 `--screen` 없이)
- **화면 설정이 없으면 멈춘다**(「자막바를 먼저 재라」). 자막바 위치 · 색은 프로젝트마다 다르다 — 예전엔 국가데이터처 숫자(191,933 1538x91 · 채움 #EAEAEA · 테두리 #2A7170)가 박혀 있어 다른 프로젝트에선 조용히 엉뚱한 곳을 쟀다.
- 새 프로젝트: `python3 minstack/도구/자막바_재기.py <영상> <자막 떠 있는 초 3~6개> --out <폴더>` → `자막바_확인.jpg` 를 눈으로 보고 `화면설정_초안.json` 을 프로젝트 폴더에 `화면설정.json` 으로.
- 국가데이터처 = `minstack/검수기/화면설정_예시_국가데이터처.json` · 양식 = `화면설정_양식.json`.
- 읽는 칸: fps · subbar · text_area · bar_fill(+tol) · text_dark_max · border(+tol) · border_line.
- `screen_cfg.py` = 02 · 04 도 같이 쓰는 설정 읽기(이 폴더에 둠 — 지우지 말 것).
- 회귀(10/19): 국가데이터처 예시 설정으로 5강 정답판 앞 2분 → 고치기 전 코드와 json 바이트까지 같음.
